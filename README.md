# G-Lab

A modern full-stack web application for managing and purchasing computer parts online.

## Features

* User Registration \& Login
* Browse Computer Parts
* Search Products
* Shopping Cart
* Secure Checkout
* Admin Dashboard
* Product Management

## Tech Stack

Frontend

* HTML
* CSS
* JavaScript
* React

Backend

* Node.js
* Express.js

Database

* MongoDB

Version Control

* Git \& GitHub



## Instalation



* npm init -y
* npm install
* npm start
* npm install express
* npm install nodemon
* npm install mongoose
