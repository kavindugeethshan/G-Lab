# G-Lab
A modern full-stack web application for managing and purchasing computer parts online.

## Features
- User Registration & Login
- Browse Computer Parts
- Search Products
- Shopping Cart
- Secure Checkout
- Admin Dashboard
- Product Management

## Tech Stack

Frontend
- HTML
- CSS
- JavaScript
- React

Backend
- Node.js
- Express.js

Database
- MongoDB

Version Control
- Git & GitHub
